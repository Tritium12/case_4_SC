# Кейс 4: Ситуационный центр (Прототип)

## Как запустить
1. Установите зависимости: `pip install colorama`
2. Убедитесь, что файлы `sites.csv`, `incidents.csv`, `indicators.csv` лежат в корне проекта.
3. Запустите прототип: `python 04_prototype.py`

## Что делает прототип
- Читает данные датчиков и инцидентов.
- Рассчитывает severity (WARNING/CRITICAL/STALE).
- Выводит цветные алерты в консоль.
- Сохраняет алерты в `alerts_out.csv`.
- Ведет аудит инцидентов в `audit_log.csv`.
- Обрабатывает дедупликацию (окно 5 минут) и невалидные локации (site_99).
